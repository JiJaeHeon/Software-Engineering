# AI Companion Robot in Apartment

> 아파트의 여러 로봇이 하나의 플랫폼을 통해 협력하며 입주민의 일상과 단지 운영을 돕는 서비스.

## 프로젝트 소개

아파트에는 방문객 응대, 민원 처리, 순찰, 청소, 주차 관리, 택배 운반 등 다양한 업무가 있습니다. 이 프로젝트는 각 업무를 담당하는 로봇의 역할을 정의하고, 로봇들이 공통 플랫폼을 통해 정보를 주고받으며 협력하는 방식을 구상합니다.

현재는 **로봇 아이디어를 정리하고 서비스 흐름을 구체화하는 단계**입니다. 아래 내용은 초기 방향이며, 세부 기능과 구현 방식은 팀 논의를 통해 정합니다.

## 로봇 구성

| 로봇 | 활동 공간 | 주요 역할 | 역할의 경계 |
|---|---|---|---|
| 관리사무소 행정 지원 로봇 | 관리사무소 내부·입구 | 민원 접수, 행정·공지 안내, 처리 현황 조회, 직원 연결 | 직접 결제·최종 행정 판단·시설 수리는 하지 않음 |
| 안심 귀가 및 순찰 로봇 | 단지 공용 공간 | 야간 귀가 동행, 이상 징후 감지, 위치·상태 보고 | 침입자 제압·세대 내부 진입은 하지 않음 |
| 현관·로비 안내 로봇 | 동 현관·단지 로비 | 방문객 응대, 세대 호출, 출입 승인 요청, 길 안내 | 승인 없는 문 개방·신원 확정·방문객 추적은 하지 않음 |
| 바닥 청소 로봇 | 로비·복도·지하주차장 | 지정 구역 청소, 오염 처리, 작업 완료 보고 | 세대 내부·벽·창문 청소와 쓰레기 분리배출은 하지 않음 |
| 주차 관리 로봇 | 지하·지상 주차장 | 빈자리 안내, 주차 위반 의심 감지, 등록 차량 확인, 전기차 충전 지원 | 견인·과태료 부과·결제는 하지 않음 |
| 짐꾼·택배 운반 로봇 | 택배실·엘리베이터·복도·세대 문 앞 | 택배·짐 운반, 도착 알림, 수령 확인, 부재 시 보관·재배송 | 세대 내부 진입·물품 개봉·결제·단지 외부 반출은 하지 않음 |

**세대 내 알림 접점:** 거실 컴패니언 로봇과 월패드는 방문·주차·배송·안전 알림을 입주민에게 전달하는 접점으로 구상합니다. 별도의 로봇 상세안과 실제 연동 방식은 아직 정해지지 않았습니다.

## 플랫폼의 방향

플랫폼은 **로봇과 입주민, 관리사무소를 연결하는 공통 연결 창구**입니다.

- **정보 제공:** 로봇의 역할에 필요한 공지, 지도, 일정, 세대·차량 관련 정보를 제공합니다.
- **요청과 알림 연결:** 방문 승인, 민원, 귀가 동행, 배송 요청을 담당 사용자나 로봇에게 전달합니다.
- **로봇 간 협업:** 한 로봇이 발견한 문제를 적절한 담당자나 다른 로봇의 작업으로 연결합니다.
- **상태와 결과 관리:** 로봇의 위치·배터리·오류, 요청의 진행 상태와 처리 결과를 모아 확인합니다.
- **대화 지원:** 질문 이해와 정보 안내를 돕되, 사람의 승인이나 최종 판단을 대신하지 않습니다.

### 대표 협업 장면

- **방문객 응대:** 로비 로봇이 방문을 접수하면 플랫폼이 세대에 알리고, 입주민의 승인 결과를 출입 시스템에 전달합니다.
- **순찰·청소:** 순찰 로봇이 일반 오염을 발견하면 플랫폼이 청소 작업을 연결하고 완료 결과를 관리사무소에 알립니다.
- **주차 알림:** 주차 로봇이 차량 이동이 필요한 상황을 발견하면 플랫폼이 해당 차량과 연결된 세대에 알립니다.
- **배송 알림:** 운반 로봇이 세대 문 앞에 도착하면 플랫폼이 입주민에게 알리고 수령 결과를 관리합니다.

## 공통 원칙

- 개인정보는 업무에 필요한 만큼만 사용하고, 세대 정보와 개인 기록은 권한에 맞게 제공합니다.
- 출입문 개방처럼 승인이 필요한 동작은 사람의 명시적 승인을 거칩니다.
- 화재·침입 등 위험 상황은 일반 청소 요청과 구분하여 관리·안전 담당자에게 전달합니다.
- 각 로봇은 정해진 역할 안에서 동작하며, 해결하기 어려운 상황은 사람에게 연결합니다.
