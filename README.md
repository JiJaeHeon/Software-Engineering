## 플랫폼의 방향

플랫폼은 **로봇과 입주민, 관리사무소를 연결하는 공통 연결 창구**입니다.

- **정보 제공:** 로봇의 역할에 필요한 공지, 지도, 일정, 세대·차량 관련 정보를 제공합니다.
- **요청과 알림 연결:** 방문 승인, 민원, 귀가 동행, 배송 요청을 담당 사용자나 로봇에게 전달합니다.
- **로봇 간 협업:** 한 로봇이 발견한 문제를 적절한 담당자나 다른 로봇의 작업으로 연결합니다.
- **상태와 결과 관리:** 로봇의 위치·배터리·오류, 요청의 진행 상태와 처리 결과를 모아 확인합니다.
- **대화 지원:** 질문 이해와 정보 안내를 돕되, 사람의 승인이나 최종 판단을 대신하지 않습니다.

### 대표 협업 장면

- **방문객 응대:** 친인척도 방문객으로 접수합니다. 승인권 있는 입주민이 유효 시간 안에 승인하면 플랫폼이 개방을 요청하고, 로비 로봇은 설비 응답을 확인해 결과를 안내합니다. 거절·미응답 시에는 경비 문의를 안내합니다.
- **순찰·청소:** 순찰 로봇이 일반 오염을 발견하면 플랫폼이 청소 작업을 연결하고 완료 결과를 관리사무소에 알립니다.
- **주차 알림:** 주차 로봇이 차량 이동이 필요한 상황을 발견하면 플랫폼이 해당 차량과 연결된 세대에 알립니다.
- **배송 알림:** 운반 로봇이 세대 문 앞에 도착하면 플랫폼이 입주민에게 알리고 수령 결과를 관리합니다.

## 공통 원칙

- 개인정보는 업무에 필요한 만큼만 사용하고, 세대 정보와 개인 기록은 권한에 맞게 제공합니다.
- 출입문 개방처럼 승인이 필요한 동작은 사람의 명시적 승인을 거칩니다.
- 화재·침입 등 위험 상황은 일반 청소 요청과 구분하여 관리·안전 담당자에게 전달합니다.
- 각 로봇은 정해진 역할 안에서 동작하며, 해결하기 어려운 상황은 사람에게 연결합니다.
